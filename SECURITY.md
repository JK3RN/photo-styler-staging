# Security and privacy

Photo Styler is designed for a single local user on a trusted machine. It binds to IPv4 loopback by default and accepts loopback hosts, including `localhost` and bracketed IPv6 loopback. Host allowlisting and same-origin checks protect browser POST requests. The service has no authentication, authorization, TLS or user separation. Keep it on loopback and avoid a public reverse proxy or tunnel. Intentional non-loopback use changes the trust boundary and requires access controls outside Photo Styler.

The browser interface uses local assets, with no analytics, external fonts or remote processing. Its site storage holds the last filter settings. The selected file is sent to the local server for each render. Multipart parsing holds small uploads in memory and rolls larger uploads into the OS temporary directory. The parser closes spools when parsing finishes or fails. Exports are returned to the browser and stored according to browser download settings. Photo Styler writes preset JSON only. Its default access logs include request paths and client addresses. Normal host privileges, backups, OS swap and browser behavior remain part of the privacy boundary.

The service accepts one file and one settings part with a total request cap of 32 MiB plus 64 KiB. Settings and preset payloads are capped at 16 KiB. Upload reception times out after 30 seconds. The image limit is 16,000,000 pixels and 8192 pixels per side. There is one in-flight render per process. Output names are derived as bounded ASCII basenames. The server never uses the uploaded name as a filesystem path. Existing preset symlinks and malformed files are skipped, and preset writes replace their destination atomically. Store the data directory where only your account or container user can modify it.

For a vulnerability report, contact the project maintainers privately through the repository’s confidential reporting channel once enabled. Share the affected version and enough information to identify the issue. Avoid including personal images, credentials or private presets.
