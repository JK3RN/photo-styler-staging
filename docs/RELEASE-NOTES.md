# Photo Styler 0.1.0

First release of the standalone Photo Styler application.

Photo Styler applies palette-based styles to images on your own machine. Start with **Red CRT** or **Dusk Cyan Artwork**, edit the colors and tone, and add Floyd–Steinberg dithering, scanlines or a vignette. Preview in the browser and download a full-resolution PNG, JPEG or WebP.

- Runs locally on Linux with Python 3.12–3.14. HEIC/HEIF import is optional.
- Accepts single-frame images up to 32 MiB, 16 megapixels and 8192 pixels per edge.
- Stores named presets locally, respects source orientation, and strips source metadata on export.
