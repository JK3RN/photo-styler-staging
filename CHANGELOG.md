# Changelog

## 0.1.0 (candidate)

- Prepare the first public release of the standalone Photo Styler app.
- Import JPEG, PNG and WebP, with optional HEIF. Apply editable palettes, dithering and CRT effects, then export PNG, JPEG or WebP.
- Correct Floyd–Steinberg error diffusion and retain orientation while dropping source metadata.
- Enforce bounded uploads and image dimensions, serialize renders, and harden local preset storage and browser requests.
- Lock Python dependencies and build a non-root Docker image with a loopback-only host mapping in the installation guide.
- Add a synthetic demo, application screenshot and release verification notes.
